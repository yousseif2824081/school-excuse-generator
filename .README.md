# School Excuse Generator 

this is a small website that gives you a random funny excuse for being late to school. press a button, an excuse will appear, copy it :) there's also a "light mode" button that runs away from your mouse and does nothing, on purpose (I hate light mode).

**demo:** [Link](https://yousseif2824081.github.io/school-excuse-generator/)

## how this was made

this was made with html, css and javascript. the excuses is in an array in `script.js` and a random one gets picked on every click. the light mode button uses `pointermove` to measure the distance between the mouse and the button, and teleports it when you get too close. my biggest bug was variable names with different capital letters (`btnx` or `btnX`), which broke everything.

## ai disclosure

I used ai to generate the last 15 excuse as my mind turned its creativity off after a 35 funny excuses.
